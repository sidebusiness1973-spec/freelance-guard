# FreelanceGuard 仕事・証拠記録

**仕事の経緯を残して、相談前に慌てない。**

勤務記録・証拠メモ・重要日を整理し、働き方の確認から相談準備までを支援するアプリです。

## ダウンロード

| 端末 | 入手先 | 公開状況 |
| --- | --- | --- |
| iPhone・iPad | [App Storeで入手](https://apps.apple.com/jp/app/id6815494644) | 公開中 |
| Mac専用版「フリーランス守りナビ」 | 審査完了後に入手リンクを掲載 | 2026年10月4日時点で審査待ち |

GitHubは公式案内・サポート・開発用ファイルの掲載先です。一般利用者はApp Storeからインストールしてください。端末・OSの対応条件と最新の公開状態はApp Storeの表示で確認できます。

## 3つの使い方

1. **勤務を記録** — 日時、仕事内容、受けた指示を残す。
2. **経緯を整理** — 証拠メモや重要日をまとめ、必要な情報を見返す。
3. **相談の準備** — 働き方チェックやレポートで状況を整理する。

## 主な機能

- 働き方チェック・フリーランス法チェック
- 勤務記録・証拠メモ・期限や重要日の管理
- 相談前の情報整理・レポートとPDF出力
- 契約に関する基礎情報

iPhone版とMac専用版は別のアプリです。機能とデータ形式は各版で異なります。両端末間の自動同期を案内するものではありません。
