# フリーランス守りナビ

フリーランス・業務委託で働く方のために、  
**働き方チェック・勤務記録・証拠整理・相談準備**を支援するアプリです。

## 主な機能

- 働き方チェック
- 勤務記録の保存
- 証拠メモの整理
- 重要日・期限の管理
- レポート作成
- 相談前の情報整理

## こんな方に

- 業務委託なのに勤務時間や出社日を指定されている
- 毎日の定例ミーティングへの参加を求められている
- シフト提出や細かい業務指示がある
- 突然の契約解除に不安がある
- 報酬や契約条件の記録を残しておきたい
- 万一のトラブルに備えて証拠を整理しておきたい

## 対応予定

- iPhone
- Mac

## プライバシー

本アプリでは、利用者自身が入力した勤務記録やメモなどを管理します。  
プライバシーに関する詳細は、公開予定のプライバシーポリシーをご確認ください。
