プライバシーポリシー

フリーランス守りナビ（以下「本アプリ」）では、 利用者のプライバシーを尊重し、必要な範囲で情報を取り扱います。

入力情報について

本アプリでは、利用者が勤務記録、メモ、重要日などの情報を入力・管理します。 個人情報や機密情報を入力する場合は、利用者自身の判断と責任で管理してください。

情報の利用目的

入力された情報は、アプリ内での記録・整理・表示など、 本アプリの機能を提供する目的で利用します。

第三者提供

本ページで別途明示する場合を除き、 利用者の情報を無断で第三者へ販売・提供することを目的としていません。

外部サービス

App Store、GitHubなどの外部サービスを利用する場合、 それぞれのサービスのプライバシーポリシーが適用されます。

公開サポートへの投稿

GitHub Issuesは公開される場合があります。
氏名、住所、電話番号、メールアドレス、契約書全文、 勤務先の機密情報などを投稿しないでください。

改定

機能追加や法令・サービス変更等に応じて、 本ポリシーを改定することがあります。

お問い合わせ

GitHub Issues をご利用ください。
